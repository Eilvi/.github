# Eilvi

**Consultoría, IA y software a medida para vender, atender y trabajar mejor.**

Conectamos estrategia comercial, atención al cliente y operaciones con herramientas que la gente usa de verdad: automatizaciones, paneles de datos y aplicaciones hechas a medida del negocio.

[eilvi.com](https://eilvi.com/) · [Contacto](https://eduardosalomon.eilvi.com/contact)

## Quién está detrás

Eilvi es el estudio de [Eduardo Salomon](https://github.com/eduardosalomonm). Los proyectos públicos, demos y casos de estudio están en su perfil:

- [Margin Map](https://github.com/eduardosalomonm/margin-map): rentabilidad por producto para e-commerce, con Excel y Python.
- [Inbox Desk](https://github.com/eduardosalomonm/inbox-desk): clasificación de correos, tickets y borradores revisados por una persona.
- [CercaVet](https://github.com/eduardosalomonm/cercavet): citas, consultas y seguimientos para clínicas veterinarias.
